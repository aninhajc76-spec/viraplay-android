# ViraPlay Android

Projeto de teste do ViraPlay para Android.

- `player`: app do cliente para celular, tablet, Android TV e TV Box.
- `admin`: app ViraPlay ADM para ativar dispositivos e associar uma URL M3U autorizada.
- `shared`: código compartilhado entre os dois apps.
- `server`: referência da API/estrutura do Supabase já configuradas fora do APK.

API configurada: `https://viraplay-api.jcrstudio.workers.dev`

O projeto não contém a chave secreta do Supabase nem o `ADMIN_TOKEN`.
